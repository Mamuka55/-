Аккаунт заблокирован
Заблокированный пользователь не получает доступ к интерфейсу Epic AI,
не может отправлять запросы и не получает источники.

Проверка выполняется на backend, поэтому обойти её перезапуском не получится.
Если заблокировали по ошибке — разблокируйте аккаунт из админ-панели
(Пользователи → Блокировки) или командой на сервере:
npm run users -- --unblock <id> · список: npm run users
